title: "Anthropic Enterprise"
description: "Bills from Anthropic's Enterprise Analytics API."
---

For organizations on Anthropic's Enterprise plan, billed for usage at API rates.

## Connect {#connect}

Under _Bills_, add an Enterprise Analytics API key. The first pull loads the current and previous period.

## What the close reconciles against {#reconciles}

The Enterprise Analytics cost report at list price, with the discount as its own line. Figures become final about 30 days after the period ends, so the close of a period waits for them.
