For organizations that pay Anthropic per token through the Console or API keys.

## Connect {#connect}

Under _Bills_, add a Console admin key. Token Controller reads the Usage and Cost report.

## What the close reconciles against {#reconciles}

The Usage and Cost report, per workspace and day. List value is money.
