Actual cost against each token budget, whatever tag filter it sits on: a person, a ticket, a project, a team. Each row opens down to tickets and token entries.

## Reading it {#reading}

Each row shows the token budget, the actual cost and the difference. Overrun is actual above token budget; underrun is actual below.

## Look at both {#look}

An overrun may be a problem. An underrun may mean someone can teach the others, or that the next [token forecast](/account/token-budgets) should be lower. Closed periods feed the next forecast.
