Every table in the web app can be downloaded as CSV.

## CSV {#csv}

Use the download button on any table: token entries with their tags, the cost sheet, reports. The cost sheet export can add any tag name as a column. The file holds exactly what the table shows, with your filters.

## More {#more}

For live data in a spreadsheet, use the [reporting API](/report/reporting-api). To take everything with you, use the [raw export](/report/raw-export).
