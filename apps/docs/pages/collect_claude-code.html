The Claude Code mod records what Claude Code spends, turn by turn, and shows where it went without leaving the session.

Install

# inside Claude Code
/plugin marketplace add tokencontroller/claude-code
/plugin install token-controller

Then connect it to your organization with the CLI (tc connect), or leave it local.

Where it runs

Where Claude Code runsWhat the mod does
Terminal on macOS, Windows, LinuxRecords and shows everything below.
Claude desktop app, Code tabRecords and shows everything below.
VS Code panel, CI, cloud sessionsRecords token entries; shows nothing.

Nothing shows while no Claude Code session is open. People who use other agents use the CLI and the web app.

What it records

After every turn the mod takes Claude Code's own usage figures: tokens by kind, the model and the cost. Together they make the session's draft token entry. During the session the mod writes the summary with a small model call of its own, so the summary exists even if the session is closed abruptly. A session is split into segments when the branch or working directory changes; see Sessions and subagents.

What it shows

  • A band above the prompt with the headline number, attributed against unattributed, and a note when your token sheet is late.
  • A pane beside the conversation with small charts and filters, the review list, submit, and rule editing.

Commands

/tc ticket KD-214     # set this session's ticket
/tc tag purpose=spike # set any other tag
/tc report            # a report table, right in the session
/tc submit            # submit your token sheet

You can also ask Claude, for example "what did KD-214 cost this week?", and the mod answers with a report table.
