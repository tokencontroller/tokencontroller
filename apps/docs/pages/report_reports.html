Reports show cost from both sides: by person and team, and by client, project and ticket. A report is a saved tag filter with a grouping, so any tag works, such as cost per feature for client: acme. Every report can be shown in another currency, or as shares of the period instead of money. Each person sees the reports for what their role covers.

Token budget vs actualWhich people, tickets and projects ran over or under?
Agent harness reportsWhat does each agent harness, agent name and model cost?

Cost sheetWhat did a closed period cost, per project and ticket?

Summaries

Every token entry carries the agent's summary, so a number in a report can always be opened down to what the work was.

Status

Submitted token entries count at once. With approval on, reports can show all of them or approved ones only.
