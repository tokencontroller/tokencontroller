Sync tickets from Azure DevOps, with their titles, descriptions, parents and assignees.

Connect

In the web app, open Settings, then Ticket systems, and add an API token from Azure DevOps. No Azure DevOps sign-in is needed. Whoever connects a ticket system answers for that data flow.

Sync

Tickets sync every 15 minutes, or on demand. Map each Azure DevOps project to a Token Controller project; the ticket key pattern follows from it. See Projects and tickets.
