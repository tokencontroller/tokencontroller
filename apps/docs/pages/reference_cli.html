Every tc command.

Commands

CommandWhat it does
tc connect URLConnect to an organization with an invite link, or to a self-hosted instance.
tc statusOrganization, person, agents found, rules, and today's cost and share on tickets.
tc reviewList draft token entries and their tags.
tc tag N NAME=VALUE…Set tags on token entry N, such as ticket=KD-214 or purpose=learning.
tc split N TICKET=SHARE…Split token entry N between tickets, such as KD-231=60 KD-240=40.
tc submitSubmit your token sheet.
tc report --by TAG|dayCost in a table, by any tag name or by day. --filter team=web limits it.
tc export --csvAll token entries as CSV.
tc rulesList, add and order personal rules.
tc config KEY VALUESettings, such as classifier.

Every command takes --help.
