The close locks a period, a calendar month, so its token entries and their tags can no longer change. The period keeps the tag map it was closed with. It produces the cost sheet.

Closing a period

  1. Check the bill.

    The period's bill is in, from the API or as CSV.

  2. Look at what is open.

    Unattributed token entries, late token sheets, and with approval on, unapproved token entries.

  3. Send back what is wrong.

    Reject a token entry to its agent manager with a reason.

  4. Close.

    A controller closes the period. Token entries, including unattributed ones, and residual add up to the bill.

With approval on, a period cannot be closed while a token entry in it is unapproved.

After the close

Token entries in the period are locked. The period keeps the price table it was closed with. Corrections are adjustments. A token sheet submitted after the close becomes an adjustment to that month, marked late. Hand finance the cost sheet.
