Every release of the service, the Claude Code mod and the CLI. The hosted service runs the latest version. A self-hosted instance upgrades by pulling the new image; see Upgrades and backups.

Versions

Version numbers follow semantic versioning. A new major version can change the API or the database. Read its entry before you upgrade a self-hosted instance. The Docker image is tagged with each version, such as ghcr.io/tokencontroller/tokencontroller:1.0.

1.0.0

First release.

  • The Claude Code mod and the CLI, tc, which read session files, place token entries with your rules and submit token sheets.
  • Telemetry ingest over OpenTelemetry for Claude Code, Codex CLI, Gemini CLI, Copilot CLI and Cursor.
  • The token entries endpoint for any other agent, and token entries by hand or from a CSV file.
  • The GitHub Action for agents that run in CI, such as a PR review bot.
  • Rules, repository mappings and ticket key patterns that place token entries on tickets and projects, and an optional classifier on your own machine.
  • Bills from Anthropic and OpenAI, and any bill by CSV.
  • Ticket sync from Jira Cloud, Azure DevOps and GitHub Issues.
  • Token budgets and token forecasts, compared with actual cost.
  • Approval, the close, adjustments and the cost sheet.
  • Reports by person, team and any tag and by client, project and ticket, tags with a tag map for the cost center and the cost object, the outliers report and the agent harness report.
  • CSV exports, the reporting API and the raw export.
  • The self-hosted Docker image, the same as the hosted Team plan.
