The fields of a token entry, as the token entries endpoint and CSV import take them.

Fields

FieldMeaning
agent_harnessThe product the agent ran on. Required.
agent_nameA label for the agent, such as "review bot". Optional.
modelThe model that did the work. Required.
started_at, ended_atWhen the session started and ended. Required.
tokensCounts by kind: input, output, cache_write, cache_read. Required.
reported_costThe agent's own cost figure. Optional; without it the list value is computed.
summaryWhat the session did, from one line to a short report. With the tag values, the only text.
ticket, projectWhere it belongs. Optional. A ticket named here wins over every rule; without one, rules place it.
tagsAny tags from the organization's list, such as {"team": "web", "purpose": "code-review"}. One value per tag name. Optional. Tags sent here win over inherited ones.
signalsBranch, working directory, repository, pull request number, subagent type, and ticket keys found in prompts, the session title and the pull request title. Optional.
session_idJoins the token entry to telemetry. Optional.

Set by Token Controller: agent manager, list value, billed value, inherited tags, splits, status.
