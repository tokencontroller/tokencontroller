This page lists everything Token Controller does and everything it will not do. The list is fixed: what is not here will not be built.

What is in

AreaWhat you get
CollectThe Claude Code mod for macOS, Windows and Linux, in the terminal and in the desktop app. The CLI, which works with no service connected and exports for a spreadsheet. Telemetry push from Claude Code, Codex, Gemini CLI, Copilot CLI and Cursor Enterprise. The GitHub Action for CI agents. The token entries endpoint for any other agent. Manual entry and CSV import in the web app.
AttributeRules on branch, repository, pull request and ticket keys. Sessions split into segments when the branch or directory changes. Review and submit of token sheets. An optional classifier on your own machine, with one reference script that uses an open local model.
Close and reportBills from the Anthropic and OpenAI admin APIs, as CSV or typed in. Approval and reject. The monthly close and the cost sheet. Adjustments after close. Reports on token budget versus actual, agent harness, agent name, model and outliers. Exports: CSV from every table, a read-only reporting API, and a full raw export.
PlanToken budgets on people, tickets, projects and periods. Token forecasts from past cost. A cadence for token sheets, with reminders when one is late.
ConnectTicket sync with Jira Cloud, Azure DevOps and GitHub Issues. Sign-in by magic link. OIDC and SCIM on the Enterprise plan. Bills from Bedrock, Vertex and Foundry as CSV, or through a connector on an Enterprise plan contract.

What is out

AreaNot built
AppsNo mobile app. No native desktop app, including menu bar and tray apps; the Claude Code mod shows the same numbers inside Claude Code. No Slack bots, browser extensions or embedded dashboards. The web app is readable on a phone.
SpendingNo spend alerts and no spend caps. Your provider offers both. A token budget never stops spending. The only reminder is for a late token sheet.
Agent estimatesAgents do not estimate their own cost, do not explain variances, and get no estimates fed back. Agent self-estimates match actual cost poorly, with a correlation of about 0.4.
ClassifierNo bundled model. The classifier is a program you run on your own machine.
Session filesSession files are read for Claude Code and Codex only. Other agents report by telemetry or through the token entries endpoint.
Ticket systemsOnly Jira Cloud, Azure DevOps and GitHub Issues. Tickets from other systems can be created by hand.
Enterprise onlyCloud bill connectors and telemetry passthrough to your own collector exist only on an Enterprise plan contract.
OrganizationOne account is one organization. An agency with a separate AI account per client runs one organization per client. The Team plan stops at 150 members.
Privacy modesNo aggregate-only mode. People managers see cost per person within their scope, and controllers see all of it.
Local toolNo sync between one person's machines. Each machine submits its token entries on its own.
Flat feesOnly metered usage is accounted for: tokens and per-call fees. Seats, subscriptions and other flat fees stay off the bill and off the cost sheet. What the agent harness does not report shows as residual.
Org chartNo team tree. People carry group labels for reporting; groups carry no token budget.
ChatUsage in a provider's own chat app is not an agent's and never becomes a token entry. It shows as residual.
Your clientsToken Controller ends at the cost sheet. It does not invoice your clients, add markups or bill on your behalf. Pass-through happens in your own invoicing tool.
Open sourceIssues on GitHub are open. Pull requests from outside are not accepted.
