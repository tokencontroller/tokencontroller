The fields of a bill, as the bills endpoint and CSV upload take them.

Fields

FieldMeaning
periodThe calendar month, such as 2026-09.
cost_sourceSubscription, seat, usage at API rates, API key, cloud marketplace or reseller.
gross, discount, credit, netThe amounts.
currencySuch as USD.
exchange_rateTo the organization's reporting currency, at the bill's date. Optional; Token Controller fills it in when left out.
revisionSet by Token Controller when a provider restates a bill.
