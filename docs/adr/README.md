# Architecture decision records

One file per decision, numbered in the order they were made. Each one says what was decided and why, in a few sentences. The docs at docs.tokencontroller.com say what the product does; these records say how it is built and why. A record never contradicts the docs. When a decision changes, the old record stays and says which record replaces it.

The Enterprise plan features are built in a private repo. Decisions about how they plug in and how instances are run are recorded there.
